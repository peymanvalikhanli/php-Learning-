
# php-Learning-

## 📘 مقدمه | Introduction

این پروژه با هدف آموزش و تمرین زبان برنامه‌نویسی PHP ایجاد شده است و شامل مثال‌ها، پروژه‌های کوچک و نکات مهم برای یادگیری بهتر PHP می‌باشد.  
This project is designed to teach and practice PHP programming language, including examples, small projects, and key points for better PHP learning.

---

## 🧩 ساختار پروژه | Project Structure

```
php-Learning-/
├── project/        # پروژه‌های نمونه | Sample projects
├── session1/       # جلسه ۱: مبانی PHP | Session 1: PHP Basics
├── session2/       # جلسه ۲: متغیرها و انواع داده | Session 2: Variables and Data Types
├── session3/       # جلسه ۳: عملگرها | Session 3: Operators
├── session4/       # جلسه ۴: ساختارهای کنترلی | Session 4: Control Structures
├── session5/       # جلسه ۵: توابع | Session 5: Functions
├── session6/       # جلسه ۶: آرایه‌ها | Session 6: Arrays
├── session7/       # جلسه ۷: کار با فرم‌ها | Session 7: Working with Forms
├── session8/       # جلسه ۸: نشست‌ها و کوکی‌ها | Session 8: Session and Cookie Management
├── session9/       # جلسه ۹: برنامه‌نویسی شی‌گرا | Session 9: Object-Oriented Programming
├── session10/      # جلسه ۱۰: پایگاه داده | Session 10: Database Interaction
└── LICENSE         # مجوز | License
```

---

## 🛠️ پیش‌نیازها | Prerequisites

- PHP نسخه ۷.۴ یا بالاتر | PHP version 7.4 or higher  
- وب سرور محلی مانند XAMPP یا WAMP | Local web server like XAMPP or WAMP  
- مرورگر وب | Web browser

---

## 🚀 نحوه استفاده | Usage

1. مخزن را کلون کنید | Clone the repository:

   ```bash
   git clone https://github.com/peymanvalikhanli/php-Learning-.git
   ```

2. پوشه پروژه را در ریشه وب‌سرور محلی خود قرار دهید | Place the project folder in your local web server's root directory.

3. سرور را راه‌اندازی کرده و در مرورگر باز کنید | Start the server and open in your browser.
